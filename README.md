# MathAlarm

MathAlarm — учебный Android-будильник. Пользователь выбирает время, дни недели и количество арифметических примеров. В назначенное время приложение воспроизводит сигнал; правильные ответы на все примеры останавливают его.

## Как проверить на телефоне

1. Установите APK из последнего релиза GitHub и откройте MathAlarm.
2. Разрешите уведомления. Если приложение попросит разрешить точные будильники, откройте настройки из главного экрана и разрешите их.
3. Нажмите **Добавить будильник**. Для быстрой проверки нажмите **Проверить: поставить через 2 минуты**.
4. Выберите сложность и количество примеров, затем нажмите **Сохранить**. На главном экране должно быть **Вкл** и показано время следующего сигнала.
5. Заблокируйте телефон и дождитесь сигнала. Откройте уведомление, если экран с заданиями не открылся сам. Неправильный ответ не продвигает решение; после всех правильных ответов сигнал прекращается.

Кнопка **Проба** открывает примеры без сигнала. Варианты **Изменить**, **Вкл/Выкл** и **Удалить** доступны на карточке каждого будильника.

## Реализация

- `main.py` — интерфейс Kivy с учётом системных панелей Android.
- `mathalarm/model.py`, `storage.py`, `schedule.py`, `examples.py` — модель, локальная база SQLite, расписание и задания.
- `mathalarm/android.py` — вызов Android-компонентов из Python.
- `android_src/` — `AlarmManager.setAlarmClock()`, приём сигнала, повтор после перезагрузки и смены времени, foreground service с системным звуком и уведомлением.
- `buildozer.spec` — конфигурация APK, включая разрешения и Java-классы.

Сигнал воспроизводится в Android foreground service и не зависит от запущенного интерфейса. После перезагрузки будильники восстанавливаются из сохранённого расписания. Уведомление позволяет открыть экран задач; возможность автоматического показа поверх блокировки зависит от разрешения полноэкранных уведомлений в конкретной версии Android.

## Проверка исходников

```text
python -m unittest discover -s tests -v
```

Сборку APK выполняет GitHub Actions. APK следует проверить на реальном Android-устройстве перед использованием как основного будильника: время сигнала, экран блокировки, громкость, разрешения и восстановление после перезагрузки зависят от системы и производителя телефона.
