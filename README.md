# MathAlarm

MathAlarm — учебное Android-приложение-будильник. Пользователь задаёт время и дни недели; после сигнала он должен решить несколько арифметических примеров. Первый релиз рассчитан на один телефон без интернета и регистрации.

## Код на Python

- `main.py` — прототип интерфейса Kivy: создание, изменение и удаление будильников, ручная демонстрация экрана примеров.
- `mathalarm/model.py` — проверяемая модель будильника.
- `mathalarm/storage.py` — локальная база SQLite.
- `mathalarm/examples.py` — примеры трёх уровней и проверка ответов.
- `mathalarm/schedule.py` — расчёт ближайшего повторения.
- `buildozer.spec` — начальная конфигурация упаковки Python-приложения для Android.
- `tests/test_core.py` — проверки основных сценариев без Android.

В репозитории нет собственного Kotlin- или Java-кода. При сборке Buildozer и python-for-android создают служебные Android-компоненты автоматически.

## Что уже работает

Модель, SQLite-хранилище, генератор заданий и расчёт даты покрыты автоматическими тестами. Интерфейс Kivy позволяет управлять записями и вручную открыть демонстрацию решения примеров.

**Системное срабатывание ещё не реализовано.** Приложение пока не звонит по расписанию при закрытом экране и не восстанавливает события после перезагрузки. Для выполнения US-03 нужен отдельный прототип вызова Android AlarmManager из Python, обработка системных разрешений и проверка на двух телефонах. Не следует использовать текущий прототип как основной будильник.

## Запуск и проверка

```text
python -m unittest discover -s tests -v
python main.py
```

Для запуска интерфейса требуется установленный Kivy. Для Android-сборки нужен Buildozer в Linux или WSL на Windows. Конфигурация `buildozer.spec` подготовлена, но APK и работа на устройстве пока не проверялись.

Архитектурные решения описаны в [docs/architecture.md](docs/architecture.md).
