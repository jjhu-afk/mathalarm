# MathAlarm

MathAlarm — Android-будильник, который прекращает сигнал после решения заданного числа арифметических примеров. Первый релиз рассчитан на работу на одном телефоне без интернета и регистрации.

## MVP

- Создание будильника с выбором времени и дней недели.
- Изменение, выключение и удаление будильника.
- Сигнал в заданное время при закрытом приложении и заблокированном экране.
- Отключение сигнала после правильных ответов на примеры.
- Выбор сложности и количества примеров.

## Начало реализации

В репозитории добавлены доменная модель [Alarm.kt](app/src/main/java/ru/penzgtu/mathalarm/model/Alarm.kt), граница системного планировщика [AlarmScheduler.kt](app/src/main/java/ru/penzgtu/mathalarm/scheduler/AlarmScheduler.kt) и [описание архитектуры](docs/architecture.md). Эти файлы фиксируют структуру локального решения на Kotlin для Android.

Собираемого Android-модуля пока нет. Следующий шаг — подключить Room и AlarmManager, затем проверить точное срабатывание, блокировку экрана и восстановление расписания после перезагрузки на реальном устройстве.
