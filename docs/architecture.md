# Архитектура MathAlarm на Python

## Границы MVP

Один пользователь и один Android-телефон. Нет регистрации, сервера, сетевого API и синхронизации. В MVP входят создание, изменение и удаление повторяющихся будильников, выбор сложности и числа примеров, точное срабатывание и прекращение сигнала после правильных ответов.

## Компоненты

| Компонент | Реализация | Состояние |
| --- | --- | --- |
| Интерфейс | Kivy, `main.py` | Прототип |
| Модель будильника | `mathalarm/model.py` | Реализована |
| Хранение | `mathalarm/storage.py`, SQLite | Реализовано |
| Примеры и проверка | `mathalarm/examples.py` | Реализованы |
| Расчёт ближайшего запуска | `mathalarm/schedule.py` | Реализован для обычных локальных дат |
| Точный системный сигнал | Android AlarmManager через Pyjnius | Планируется, требует испытаний |
| Восстановление после перезагрузки | Android BOOT_COMPLETED и повторное планирование | Планируется, требует исследования |

Маска `days_mask` использует семь бит: понедельник — бит 0, воскресенье — бит 6. Постоянно хранятся только записи будильников. Текущее арифметическое задание и число верных ответов существуют в памяти во время активного сеанса.

## Ограничения

Kivy и python-for-android позволяют выпускать Android-приложение с исходным кодом на Python. Системный точный сигнал, запуск поверх заблокированного экрана и восстановление после перезагрузки зависят от Android API и разрешений. Простой таймер Kivy не может считаться решением US-03. До проверки AlarmManager на устройствах технический риск RSR-01 остаётся открытым.

Android-сборка через Buildozer на Windows выполняется в WSL. Текущий репозиторий содержит начальный Python-прототип; APK не собирался и тесты на телефонах не проводились.
