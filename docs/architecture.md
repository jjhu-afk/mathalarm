# MathAlarm: архитектура MVP

Локальное Android-приложение без регистрации, сервера и сетевого API.

Планируемые компоненты: экраны списка и редактирования будильников; экран решения
примеров; планировщик через AlarmManager; локальное хранение будильников в Room;
генератор арифметических заданий. При изменении будильника расписание должно
обновляться, после перезагрузки устройства включённые будильники должны
планироваться заново.

В текущем коммите реализованы доменная модель Alarm и интерфейс AlarmScheduler.
Маска daysMask использует семь бит: понедельник — бит 0, воскресенье — бит 6.
Интерфейс отделяет прикладную логику от конкретного вызова Android API.

Источник требований: лабораторные работы № 1 и № 2 команды MathAlarm.
Это начальная структура проекта; сборка Android-приложения и проверка на устройстве
пока не выполнялись.
